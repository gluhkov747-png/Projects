# Projects
проекты по курсу

ROADMAP:

🟢 БЛОК 1. СИНТАКСИС (недели 1–2)

Уметь писать рабочий код без ошибок.

· Переменные и базовые типы (int, float, str, bool)
· Списки (list) и срезы ([:3], [::-1])
· Словари (dict) — обращение, добавление, перебор
· Кортежи (tuple) и множества (set) — когда использовать
· Условия (if/elif/else) + тернарный оператор
· Циклы (for, while) + break, continue
· Функции (def), аргументы, return
· Работа со строками (.split(), .join(), .strip(), f-строки)
· Обработка ошибок (try/except) — базово
· Генераторы списков
---

🟡 БЛОК 2. РАБОТА С ДАННЫМИ (недели 3–4)

Это 80% задач на фрилансе.

· Чтение/запись файлов (open, with, encoding='utf-8')
· Работа с csv (модуль csv или pandas — проще pandas)
· Работа с json (json.loads, json.dumps)
· Списковые включения ([x*2 for x in data if x > 0])
· Функции map, filter, lambda
· Сортировка (sorted(), key=lambda)
· Модуль os — создать папку, пройтись по файлам

Практика: скрипт, который берёт папку с файлами, собирает их в один CSV и чистит пустые строки.

---

🟠 БЛОК 3. ИНТЕРНЕТ И ПАРСИНГ (недели 5–6)

Первые реальные заказы — почти всегда парсинг.

· Библиотека requests — получить страницу, заголовки, параметры
· Библиотека BeautifulSoup — найти тег, класс, атрибут
· Извлечь текст, ссылки, картинки из HTML
· Обойти пагинацию (следующая страница)
· Сделать паузы (time.sleep) — чтобы не забанили
· Сохранить результат в csv или json

Практика: спарсить заголовки новостей с любого сайта за последние 3 дня.

---

🔵 БЛОК 4. GIT И КОМАНДНАЯ СТРОКА (неделя 7)

Без этого не берут даже на стажировку.

· git init, clone, add, commit, push, pull
· Создать репозиторий на GitHub и залить код
· Написать понятный README.md (что делает проект)
· Базовые команды терминала: cd, ls, mkdir, python script.py

---

🟣 БЛОК 5. ВЕБ-ФРЕЙМВОРК (МИНИМАЛЬНО) — недели 8–9

Нужно для фриланса "сделать бота/сервер".

· Установить Flask
· Сделать один маршрут (@app.route('/'))
· Принять параметры из запроса (request.args)
· Вернуть json (jsonify)
· Запустить сервер локально и проверить

Практика: API, которое по имени пользователя возвращает его ID из словаря.

---

🟤 БЛОК 6. БОТЫ И АВТОМАТИЗАЦИЯ (недели 10–11)

Самый быстрый способ заработать первые деньги.

· Телеграм-бот на python-telegram-bot или aiogram
· Команды /start, /help
· Обработка текстовых сообщений
· Кнопки (InlineKeyboard)
· Отправка файлов, картинок

Практика: бот, который по запросу присылает курс доллара (парсит Центробанк или пользуется API).
